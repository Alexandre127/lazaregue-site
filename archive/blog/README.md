# Archive — textes du blog (rubrique « Analyses »)

Sources des textes de l'ancienne rubrique `/blog`, **supprimée le 10 sept. 2026**
(le site n'a jamais été public, rien n'était indexé — suppression sèche, sans
redirection). Conservés ici **hors des routes** comme matière rédactionnelle ;
exclus du build (cf. `exclude` dans `tsconfig.json`).

- `analyses.ts` — les 9 analyses de l'index (titres, chapôs, métadonnées).
- `articles-data.ts` — corps complets des articles du gabarit `[slug]`.
- `ai-act-preuve.ts` — l'étude « L'AI Act, un droit de la preuve de la
  conformité ? » (texte intégral).

Ces fichiers ne sont plus rendus par aucune page. Pour réutiliser un texte,
le recopier dans la page cible ; ne pas réimporter ce dossier dans `app/`.
